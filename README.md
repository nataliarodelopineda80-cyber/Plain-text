# Sistema de Gestión de Estudiantes (SGE)

## Descripción

Aplicación desarrollada en Java que permite registrar, mostrar y buscar estudiantes mediante una consola de comandos.

## Funcionalidades

- Agregar estudiantes.
- Mostrar estudiantes registrados.
- Buscar estudiantes por ID.
- Salir del sistema.

## Estructuras de control utilizadas

- if
- switch
- while
- for
- try-catch

## Variables especiales

- banderaSalir
- totalEstudiantes

## Almacenamiento

- ArrayList
